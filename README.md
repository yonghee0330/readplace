# 비북스 온라인 서가 — 1차 버전: 읽기 모드

부천 원미동 동네 서점 **비북스(Bbooks)** 분위기의 온라인 서가입니다.
말없이 머물며 저작권이 끝난 한국 근대 문학을 한 권씩 꺼내 읽는 공간입니다.
이번 1차 버전은 **책 읽기 모드 하나만** 있습니다. (3D 공간·멀티플레이·아바타는 다음 단계)

- 빌드 없음, 외부 라이브러리 없음, 서버 없음 — 정적 파일만으로 동작
- 로그인·결제·외부 트래킹·개인정보 수집 없음. 읽은 기록은 그 기기의 브라우저(localStorage)에만 저장

---

## 1. 실행 방법

책 데이터를 `fetch`(파일 불러오기)로 읽기 때문에 `index.html`을 더블클릭하면 열리지 않습니다.
**이 폴더에서 로컬 서버를 띄운 뒤** 브라우저로 여세요.

**Mac / Linux (파이썬, 설치 없이)**

```bash
cd ~/Documents/bbooks
```

```bash
python3 -m http.server 8000
```

브라우저에서 <http://localhost:8000> 을 엽니다. 끌 때는 터미널에서 `Ctrl + C`.

**Node.js가 있다면**

```bash
npx serve .
```

**Windows**: 파이썬이 있으면 `python -m http.server 8000`(명령이 `python3`가 아니라 `python`), 없으면 `npx serve .`를 쓰세요.

> 같은 와이파이의 아이폰으로 보려면: Mac에서 서버를 띄운 뒤 아이폰 사파리에서 `http://(Mac의 IP 주소):8000` 으로 접속합니다. Mac의 IP는 시스템 설정 → 네트워크에서 확인할 수 있습니다.

## 2. 조작법

| 하고 싶은 것 | 데스크톱 | 모바일 |
|---|---|---|
| 다음 쪽 | `→`, `PageDown`, `Space`, 오른쪽 면 클릭, 왼쪽으로 드래그 | 오른쪽 2/3 탭, 왼쪽으로 스와이프 |
| 이전 쪽 | `←`, `PageUp`, 왼쪽 면 클릭, 오른쪽으로 드래그 | 왼쪽 1/3 탭, 오른쪽으로 스와이프 |
| 처음 / 끝 | `Home` / `End` | 판권 면의 "처음부터 다시" |
| 글자 크기 | 하단 `가−` `가+`, 키보드 `-` `+` | 하단 `가−` `가+` |
| 서가로 | 상단 "돌아가기", `Esc` | 상단 "돌아가기" |

- 화면이 넓으면 양면 펼침, 좁으면 한 면으로 바뀝니다(폭 860px 이상이고 가로가 더 길 때 양면).
- 쪽은 화면 크기와 글자 크기에 맞춰 **자동으로 다시 나눕니다**. 그래서 같은 책도 기기마다 전체 쪽수가 다를 수 있습니다. 이어 읽기는 "몇 쪽"이 아니라 "어느 작품의 어디쯤"으로 기억하므로, 글자 크기를 바꾸거나 다른 크기 화면에서 열어도 읽던 대목으로 돌아옵니다.
- **오늘 읽은 시간**은 읽기 화면이 열려 있고 화면이 보일 때만 잽니다. 10분 동안 아무 조작이 없으면 "쉬는 중"으로 멈춥니다. 날짜가 바뀌면 0부터 다시 셉니다.
- **빗소리**는 기본 꺼짐입니다. 파일 없이 Web Audio로 그 자리에서 만든 소리입니다.
- 손대지 않고 4초가 지나면 위아래 막대가 흐려집니다. 움직이면 다시 또렷해집니다.

## 3. 파일 구조

```
index.html          화면 뼈대 (입장 · 서가 · 읽기)
css/style.css       디자인 전체 (종이/밤 테마 포함)
js/app.js           입장 화면, 책 불러오기, 서가, 화면 전환, 표지 그림(SVG)
js/reader.js        읽기 모드: 쪽 나누기, 넘김 애니메이션, 입력, 타이머
js/storage.js       localStorage 저장 (읽던 위치, 읽은 시간, 설정)
js/sound.js         빗소리 (Web Audio)
books/index.json    서가에 꽂을 책 목록과 순서
books/*.json        책 한 권씩
```

## 4. 책 추가 방법

1. `books/` 폴더에 새 json 파일을 만듭니다. (예: `books/kimyujeong-camellia.json`)
2. 아래 모양을 복사해 내용을 채웁니다.
3. `books/index.json`의 `books` 목록에 파일 이름을 추가합니다. 목록 순서가 서가 순서입니다.

```json
{
  "id": "kimyujeong-camellia",
  "title": "동백꽃",
  "author": "김유정",
  "year": "1936",
  "format": "prose",
  "excerpt": true,
  "cover": { "color": "#8a3b2e", "accent": "#f2c9a0", "ink": "#fbf1e6", "pattern": "petals" },
  "intro": "서가 속표지에 들어갈 한두 줄 소개.",
  "source": {
    "original": "원전: 작가, 「작품」, 『실린 곳』, 발표 연도",
    "works": "수록 작품 또는 발췌 범위",
    "text": "어떤 판본을 따랐는지",
    "copyright": "작가(생년–몰년). 저작권 보호기간이 끝나 대한민국에서 퍼블릭 도메인",
    "verified": false
  },
  "pages": [
    "> 첫머리 일부\n\n첫 문단입니다.\n두 번째 문단입니다.",
    "다음 대목입니다."
  ]
}
```

| 항목 | 설명 |
|---|---|
| `id` | 영문 소문자·숫자·하이픈만. 주소(`#/book/id`)와 저장 기록의 이름표가 됩니다. **나중에 바꾸면 읽던 기록이 끊깁니다.** |
| `format` | `"poem"`(시: 줄바꿈 그대로, 빈 줄은 연 나눔) 또는 `"prose"`(소설: 한 줄이 한 문단) |
| `excerpt` | 일부만 옮긴 책이면 `true` → 표지에 "일부", 마지막 면에 "발췌 끝" |
| `cover.pattern` | 표지 그림: `petals`(꽃) `stars`(별) `ripple`(물결) `grapes`(포도) `field`(들판) `feather`(깃털) `rain`(비) |
| `pages` | 문자열 배열. 아래 표시를 쓸 수 있습니다. 화면에서는 크기에 맞춰 다시 나뉘므로, 여기서는 **작품·대목 단위**로 나눠 두면 됩니다. |
| `source` | **필수.** `original`(원전)과 `copyright`(저작권 근거)가 없으면 그 책은 서가에 꽂히지 않습니다(브라우저 콘솔에 경고). |
| `source.verified` | 원문과 대조를 마치면 `true`. `false`면 판권 면에 "원문과 한 번 더 대조하고 있는 판본" 문구가 나옵니다. |

`pages` 안에서 쓰는 표시:

- `# 제목` → 작품 제목
- `> 안내` → 작은 안내 글씨 (예: `> 첫머리 일부`)
- 빈 줄(`\n\n`) → 시는 연 나눔, 소설은 문단 사이

### 저작권 원칙

- **저작권이 끝난(퍼블릭 도메인) 한국 작품만** 넣습니다. 대한민국에서는 일반적으로 **1962년까지 세상을 떠난 저자**의 작품은 보호기간이 끝났습니다(1963년 이후 사망자는 사후 70년). 공동 저작·번역·주석이 붙은 판본은 따로 따져야 하며, 애매하면 아래 공식 사이트에서 확인한 뒤 넣으세요.
- 출처(`source`)가 확실하지 않으면 넣지 않습니다.
- 최신 기준은 한국저작권위원회 "공유마당"(<https://gongu.copyright.or.kr>)에서 확인하세요.

### ⚠ 공개 전에 할 일: 원문 대조

이번 1차 본문 7권은 작업 환경에서 위키문헌 등 원문 사이트에 접속할 수 없어, **널리 쓰이는 현대 표기 통용본을 기준으로 입력**했습니다. 그래서 모든 책이 `"verified": false`입니다.
공개 전에 아래 자료와 한 번씩 대조하고, 맞으면 `verified`를 `true`로 바꿔 주세요.

- 위키문헌(한국어): <https://ko.wikisource.org>
- 국립중앙도서관 원문: <https://www.nl.go.kr>
- 한국저작권위원회 공유마당: <https://gongu.copyright.or.kr>

특히 소설 발췌 두 권(이상 「날개」, 현진건 「운수 좋은 날」)은 판본마다 표기 차이가 커서 대조가 꼭 필요합니다.

## 5. 배포 (GitHub Pages / Cloudflare Pages)

빌드가 없으므로 이 폴더를 그대로 올리면 됩니다.

- **GitHub Pages**: 저장소에 올린 뒤 Settings → Pages → Branch를 `main` / `/(root)`로 지정
- **Cloudflare Pages**: 새 프로젝트 → 저장소 연결 → Build command 비움, Output directory `/`

모든 경로가 상대 경로라 `사용자명.github.io/저장소이름/` 같은 하위 주소에서도 동작합니다.

## 6. 다음 단계 메모

1. **3D 서점 공간 (2차)** — three.js로 비북스 실내(서가, 창가 자리, 계산대)를 만들고, 서가의 책을 누르면 지금의 읽기 모드로 들어가게 연결. 아바타는 단순한 형태로 시작.
2. **같이 읽는 사람 표시 (3차)** — 웹소켓(실시간 연결)으로 "지금 n명이 머무는 중", 같은 책을 읽는 사람의 자리만 은은하게 표시. 이름·채팅 없이 "말없이 같이"를 유지.
3. **행동 버튼 (3차)** — "조용히 인사", "차 한 잔 놓기"처럼 말 없는 짧은 행동만. 기록·순위 없이.
4. **비북스 큐레이션 연동 (4차)** — 실제 서가 분양·독서 모임 소개글, 이번 달 추천 책과 연결.
5. 그 밖에 손볼 것 — 원문 대조 후 `verified: true`, 아이폰용 명조 웹폰트(Noto Serif KR) 도입 여부 결정, 오프라인 사용(PWA).
